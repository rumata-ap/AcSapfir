# Быстрый старт

Цель — за 5 минут получить в САПФИР оси, стены и плиту из простого чертежа AutoCAD.

## Подготовка

1. Запустите **AutoCAD 2020**.
2. Запустите **САПФИР** и откройте в нём документ с проектом (если проекта нет — плагин создаст его сам).
3. Загрузите плагин: `NETLOAD` → `bin\Debug\AcSapfir.dll`.

!!! tip "САПФИР и AutoCAD — рядом"
    Держите оба окна открытыми: плагин читает **активное окно САПФИР** (`GetActiveSapfirView()`) в момент вызова команды. Если переключить активное окно САПФИР на другой документ, следующая команда запишет объекты уже туда.

## Шаг 1. Оси

Нарисуйте парой отрезков две координационные оси.

- Выберите отрезки (можно до вызова команды — используется PickFirst).
- Выполните `Sapfir_AXES`.

В командной строке появится сообщение о контексте и созданных осях:

```
[Sapfir] Активно: <документ> / проект ID=1 / этажей: 1
  Ось 1
  Ось 2
```

Оси нумеруются в порядке выбора. Для «умной» маркировки используйте [`Sapfir_AXES_WIZ`](../commands/axes.md#sapfir_axes_wiz) — он группирует параллельные линии и умеет присваивать буквы кириллицы, цифры и шаблонные имена.

## Шаг 2. Стены

1. Нарисуйте отрезки по осям стен.
2. Выполните `Sapfir_WALLS`.
3. Выберите материал в диалоге (кнопка **Пропустить (по умолчанию)** оставит материал по умолчанию).
4. Введите толщину стены **в метрах**, например `0.2`.

```
  Материал: Бетон тяжёлый (стена)
  Стена ID=12
  Стена ID=13
```

## Шаг 3. Плита перекрытия

1. Нарисуйте замкнутую полилинию — контур плиты.
2. Выполните `Sapfir_SLABS`, выберите материал, введите толщину в метрах (`0.2`).

```
  Плита ID=14
```

## Шаг 4. Этажи (если нужно несколько)

Напишите в модели многострочные тексты там, где должны быть этажи: текст = имя этажа, **Y-координата точки вставки = отметка этажа в миллиметрах**.

Выполните `Sapfir_STOREYS` и выберите эти тексты — существующие этажи будут удалены, плагин создаст новые и рассчитает высоты как разность соседних отметок.

Альтернатива без текстов — [`Sapfir_STOREYS_WIZ`](../commands/storeys.md#sapfir_storeys_wiz): таблица «имя + отметка», шаблоны «Подвал», «1-й этаж», «Типовые ×N», «Чердак».

## Шаг 5. Правка геометрии

Плагин запоминает связь «примитив AutoCAD ↔ объект САПФИР» в XData. Поэтому после правки чертежа:

1. Подвиньте/измените отрезки и полилинии стен.
2. Выполните `Sapfir_WALL_EDIT` и выберите изменённые примитивы — геометрия стен в САПФИР обновится (толщина и материалы не затрагиваются).
