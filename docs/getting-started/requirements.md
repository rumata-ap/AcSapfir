# Требования

## Рабочее место пользователя

| Компонент | Требование | Примечание |
|---|---|---|
| ОС | Windows 7 SP1 / 10 / 11 (x64) | AutoCAD 2020 не поддерживает 32-битные системы |
| AutoCAD | **AutoCAD 2020** | сборка привязана к библиотекам именно 2020 версии |
| САПФИР | **САПФИР 2018+** с зарегистрированной COM-библиотекой `SapfirLib` | версия библиотеки в проекте — 19.0 |
| .NET Framework | **4.8** | указана в `AcSapfir.csproj` (`TargetFrameworkVersion v4.8`) |

!!! info "Почему именно AutoCAD 2020"
    В `AcSapfir.csproj` ссылки на `accoremgd.dll`, `acdbmgd.dll`, `acmgd.dll` заданы **абсолютными путями** к `C:\Program Files\Autodesk\AutoCAD 2020\`. Сборка на другой версии AutoCAD потребует правки `HintPath` (см. [Установка и сборка](install.md)).

## Требования для сборки

- Visual Studio 2019/2022 (любая редакция с поддержкой .NET Framework) **или** отдельный `msbuild`;
- установленный AutoCAD 2020 — из него берутся ссылки на API;
- установленный САПФИР — из него подтягивается COM-тип-библиотека `SapfirLib`.

## Требования к среде выполнения

- AutoCAD и САПФИР должны быть **запущены одновременно** на одной машине: плагин работает по COM-автоматизации с уже открытым приложением САПФИР.
- В САПФИР должен быть открыт документ (файл проекта). Если документа нет, плагин создаст его сам, но надёжнее открыть нужный проект заранее — иначе экспорт пойдёт в новый пустой документ.

## Проверка версии .NET Framework

```powershell
# Версия установленного .NET Framework (Release ≥ 528040 для 4.8)
Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Full' |
    Select-Object Version, Release
```

## Проверка регистрации COM-библиотеки САПФИР

```powershell
# Если библиотека зарегистрирована, вернётся путь/описание типа
New-Object -ComObject SapfirLib.Application | Select-Object -First 1
```

Если команда завершается ошибкой «Класс не зарегистрирован» (`0x80040154`), значит САПФИР не установлен или его COM-сервер не зарегистрирован — переустановите/отремонтируйте САПФИР.
