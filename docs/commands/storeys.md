# Этажи

## Sapfir_STOREYS

Создаёт этажи из выбранных многострочных текстов: **текст = имя этажа**, **Y-координата точки вставки = отметка этажа** (в миллиметрах).

**Входные примитивы:** `MText` в пространстве модели.

**Порядок работы**

1. Команда **сама** определяет документ САПФИР (активное окно → активный документ). Если документа нет:

```
Нет активного документа Sapfir
```

2. Выбор объектов.
3. Из выбранных объектов берутся только `MText`; остальные игнорируются.
4. Текст очищается от кодов форматирования (см. ниже), Y-координата точки вставки сохраняется в миллиметрах.
5. Данные сортируются **по возрастанию Y** (снизу вверх).
6. **Все существующие этажи активного проекта удаляются**, затем создаются новые.

**Что создаётся**

| Параметр | Значение |
|---|---|
| Имя этажа | очищенный текст `MText` |
| `M_LEVEL` | `Y · 0.001` (метры) |
| `M_HEIGHT` | разность отметок с **вышестоящим** этажом `(Y₊₁ − Y) · 0.001`; для верхнего этажа — `3.0` м |

!!! warning "Существующие этажи удаляются"
    Перед созданием выполняется цикл `DelStoreyByIndex(0)`, пока `CountStorey > 0`. Все объекты, размещённые на удаляемых этажах, теряют свои этажи — операция необратима (отмена в AutoCAD не восстановит структуру САПФИР).

!!! note "Очистка форматирования MText"
    Текст проходит через `StripMTextFormat()`, который удаляет коды форматирования (`\A`, `\H`, `\W`, `\S`, `\C`, `\f`, …), заменяет `\P` на пробел и удаляет фигурные скобки. Например, `{\fArial|b1;Этаж 2}` превратится в `Этаж 2`.

!!! note "Активный этаж не переключается"
    После создания этажей `storeySpf` не обновляется — плагин не выбирает «активный» этаж. Нужный этаж выберите вручную в САПФИР перед экспортом элементов.

**Пример**

| MText | Y вставки | Результат |
|---|---|---|
| `Подвал` | `-3000` | ЭП «Подвал», `M_LEVEL = -3.0`, `M_HEIGHT = 3.0` |
| `1 этаж` | `0` | `M_LEVEL = 0.0`, `M_HEIGHT = 3.0` |
| `2 этаж` | `3000` | `M_LEVEL = 3.0`, `M_HEIGHT = 3.0` |
| `3 этаж` | `6000` | `M_LEVEL = 6.0`, `M_HEIGHT = 3.0` (верхний — значение по умолчанию) |

## Sapfir_STOREYS_WIZ

Модальный генератор этажей: таблица «имя + отметка», шаблоны типовых решений. Не требует текстов в чертеже.

**Порядок работы**

1. Открывается диалог «Генератор этажей» (см. [Генератор этажей](../guides/storeys-generator.md)).
2. В таблицу добавляются этажи вручную или шаблонами.
3. По нажатию «Создать этажи» данные передаются в САПФИР.
4. Существующие этажи активного проекта удаляются, создаются новые.

**Что создаётся**

| Параметр | Значение |
|---|---|
| Имя этажа | из столбца «Имя этажа» |
| `M_LEVEL` | из столбца «Отметка, м» |
| `M_HEIGHT` | разность отметок с вышестоящим этажом; для верхнего — `3.0` м |

!!! note "Флаг `CommandFlags.Session`"
    Команда объявлена с `CommandFlags.Session`, поэтому модальный диалог работает корректно вне контекста документа (в том числе при вызове из контекстного меню и при пустом активном чертеже).

## Сравнение способов создания этажей

| | `Sapfir_STOREYS` | `Sapfir_STOREYS_WIZ` |
|---|---|---|
| Источник данных | `MText` в чертеже (имя + отметка) | таблица в диалоге |
| Требует документа САПФИР заранее | да (иначе выход с сообщением) | нет (контекст создаётся автоматически) |
| Шаблоны (Подвал/Типовые/Чердак) | нет | да |
| Сортировка | по возрастанию отметки | по возрастанию отметки |
| Высоты этажей | из разности отметок | из разности отметок |
| Замена существующих этажей | да | да |
