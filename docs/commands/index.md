# Команды

Все команды AutoCAD, регистрируемые плагином. Имена команд нечувствительны к регистру (`SAPFIR_AXES` = `Sapfir_AXES`).

| Команда | Входные примитивы | Создаёт в САПФИР | Дополнительно |
|---|---|---|---|
| [`Sapfir_AXES`](axes.md#sapfir_axes) | отрезки | координационные оси, маркировка = порядковый номер | — |
| [`Sapfir_AXES_WIZ`](axes.md#sapfir_axes_wiz) | отрезки | координационные оси с настраиваемыми именами | модальный мастер |
| [`Sapfir_Point_LOADS`](loads.md#sapfir_point_loads) | точки (`DBPoint`) | точечные нагрузки | значение нагрузки в тоннах |
| [`Sapfir_Line_LOADS`](loads.md#sapfir_line_loads) | отрезки | линейные равномерные нагрузки | диалог параметров САПФИР на каждую линию |
| [`Sapfir_Line_LOADS2`](loads.md#sapfir_line_loads2) | отрезки | линейные нагрузки с разными значениями на концах | две величины |
| [`Sapfir_SLABS`](slabs.md#sapfir_slabs) | замкнутые полилинии | плиты перекрытия | толщина, материал |
| [`Sapfir_SLAB_Holes`](slabs.md#sapfir_slab_holes) | полилиния плиты, затем контуры отверстий | отверстия в плите | плита должна иметь XData-ID |
| [`Sapfir_Found_SLABS`](slabs.md#sapfir_found_slabs) | замкнутые полилинии | фундаментные плиты | толщина, материал |
| [`Sapfir_WALLS`](walls.md#sapfir_walls) | отрезки | стены | толщина, материал |
| [`Sapfir_WALL_EDIT`](walls.md#sapfir_wall_edit) | отрезки/полилинии с XData-ID | — (обновляет геометрию стен) | требует связи по ID |
| [`Sapfir_DOORS`](openings.md#sapfir_doors) | отрезки | дверные проёмы в коллинеарных стенах | высота проёма |
| [`Sapfir_WINDOWS`](openings.md#sapfir_windows) | отрезки | оконные проёмы в коллинеарных стенах | высота проёма |
| [`Sapfir_COLUMNS`](columns.md) | полилинии | колонны (сечение = контур полилинии) | угол поворота, материал |
| [`Sapfir_BEAMS`](beams.md) | отрезки | балки прямоугольного сечения | высота и ширина сечения, материал |
| [`Sapfir_LINES`](lines.md) | отрезки | линии построения | — |
| [`Sapfir_STOREYS`](storeys.md#sapfir_storeys) | `MText` | этажи: имя из текста, отметка из Y | заменяет все существующие этажи |
| [`Sapfir_STOREYS_WIZ`](storeys.md#sapfir_storeys_wiz) | — | этажи из таблицы | модальный генератор |
| `Sapfir_test` | — | ничего | техническая заглушка, зарегистрирована в сборке |

## Общие правила работы

### Выбор объектов

Все команды используют единый механизм выбора (`AcUtilites.Selection()`):

1. Сначала проверяется **текущий набор выбора** AutoCAD (`SelectImplied`) — то есть объекты, выделенные до вызова команды (PickFirst).
2. Если набора нет, выводится запрос «Выберите примитивы для создания объектов САПФИР:».

Отмена выбора возвращает `null`, и команда молча завершается.

### Активный контекст САПФИР

Перед работой команда вызывает `ResolveActiveContext()`, который заново определяет:

- приложение САПФИР (`SapfirLib.Application`, делается видимым);
- документ — из активного окна САПФИР, иначе активный документ, иначе создаётся новый;
- проект — активный, иначе создаётся новый;
- этаж — активный (если этажей нет, создаётся «1-й этаж»).

Текущий контекст печатается в командную строку:

```
[Sapfir] Активно: Проект1 / проект ID=1 / этажей: 3
```

### Координаты

- Плоские координаты XY: миллиметры AutoCAD → метры САПФИР (`×0.001`).
- Z всех создаваемых элементов — `0`: элементы создаются на активном этаже, отметку задаёт сам этаж.
- Подробнее: [Масштабирование координат](../internals/scaling.md).

### Материалы

Команды `Sapfir_WALLS`, `Sapfir_SLABS`, `Sapfir_Found_SLABS`, `Sapfir_COLUMNS`, `Sapfir_BEAMS` предлагают выбрать материал модальным диалогом. Если нажать **«Пропустить (по умолчанию)»**, используется встроенный материал по типу элемента. Подробнее: [Материалы](../guides/materials.md).

### Обратная связь

Все команды пишут результат в командную строку AutoCAD (окно консоли — `F2`): контекст САПФИР, ID каждого созданного объекта, предупреждения.
