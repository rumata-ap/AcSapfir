# Оси

## Sapfir_AXES

Создаёт координационные оси из выбранных отрезков. Маркировка — порядковый номер линии в наборе выбора.

**Входные примитивы:** `Line` (отрезок). Точки `Z` игнорируются.

**Порядок работы**

1. Разрешается активный контекст САПФИР (`ResolveActiveContext`).
2. Выбираются отрезки (PickFirst либо запрос выбора).
3. Для каждого отрезка создаётся объект осевого размера.

**Что создаётся**

| Параметр | Значение |
|---|---|
| Тип модели | `TM_DIMENSION` (20) |
| `SetDimParam(...)` | `DIM_AXIS` (8), направление `DIM_DIR_XY` (3), марка = номер, координаты начала и конца |
| `M_MARK` | номер оси строкой |

Координаты берутся из отрезка и умножаются на `0.001` (мм → м).

```
  Ось 1
  Ось 2
```

!!! note "Нумерация"
    Нумерация идёт по порядку объектов в наборе выбора. Для содержательных обозначений (А, Б, В / 1, 2, 3 / «Ось {L}») используйте мастер [`Sapfir_AXES_WIZ`](#sapfir_axes_wiz).

!!! warning "XData не записывается"
    Команда не сохраняет ID созданной оси в примитив AutoCAD, поэтому автоматическое обновление осей (аналог `Sapfir_WALL_EDIT`) недоступно — повторный вызов создаст новые оси.

## Sapfir_AXES_WIZ

Мастер координационных осей. Группирует выбранные отрезки по направлению, для каждой группы позволяет задать правило именования с предпросмотром и создать оси одной кнопкой.

**Входные примитивы:** `Line` (отрезки). Всего линий и групп — в шапке окна: `Линий: N, групп: M`.

**Как работает группировка**

1. Первый необработанный отрезок берётся как «затравка» группы; вычисляется единичный вектор направления `(nx, ny)`.
2. Все отрезки, для которых `|скалярное произведение направлений| > 0.999` (то есть угол ≈ 0° или 180°), попадают в ту же группу.
3. Внутри группы линии сортируются по проекции середины на перпендикуляр к направлению группы — так порядок соответствует геометрическому расположению осей (слева направо или снизу вверх).
4. Нулевые по длине отрезки отбрасываются.

**Результат:** список пар (отрезок, имя). Создание осей повторяет логику `Sapfir_AXES`, но с именем из мастера; пустое имя выводится как `(без маркировки)`.

**Правила именования** — см. [Мастер осей](../guides/axes-wizard.md): «Буквы кириллицей», «Цифры», «Буквы + цифры», «Шаблон», «Без маркировки», плюс флажок «В обратном порядке».

!!! warning "XData не записывается"
    Как и `Sapfir_AXES`, мастер не сохраняет ID осей в примитивы AutoCAD.

**Сообщения**

```
  Ось А
  Ось (без маркировки)
```
