# Нагрузки

## Sapfir_Point_LOADS

Создаёт точечные нагрузки в точках AutoCAD.

**Входные примитивы:** точки (`DBPoint`).

**Диалог**

```
Введите значение нагрузки в тоннах:
```

**Что создаётся**

| Параметр | Значение |
|---|---|
| Тип модели | `TM_LOAD_1` (65557) |
| Позиция | `SetPosition(X · 0.001, Y · 0.001, 0)` |
| `M_LOAD_1` | введённое значение |

!!! note "XData не записывается"
    Связь «точка ↔ нагрузка» не сохраняется, повторный запуск команды создаст дубликаты нагрузок.

## Sapfir_Line_LOADS

Создаёт линейные нагрузки с одинаковым значением по всей длине отрезка.

**Входные примитивы:** отрезки (`Line`).

**Диалог**

```
Введите значение нагрузки в тоннах:
```

**Что создаётся**

| Параметр | Значение |
|---|---|
| Тип модели | `TM_LOAD_2` (131093) |
| Осевая линия | `GetAxisLine()` + `AddLine(TM3_LINE, точки)` |
| `M_LOAD_1`, `M_LOAD_2` | введённое значение (одинаковое на концах) |

!!! warning "Диалог параметров САПФИР вызывается на **каждую** линию"
    Метод создания вызывает `AutoParametersDlg` (родной диалог САПФИР) перед созданием каждой нагрузки. Если выбрать 10 линий, диалог появится 10 раз. Учтите это при массовом экспорте; для «тихой» пакетной работы используйте [`Sapfir_Line_LOADS2`](#sapfir_line_loads2) (он диалог не показывает).

## Sapfir_Line_LOADS2

Создаёт линейные нагрузки с разными значениями в начале и конце отрезка (трапециевидная эпюра).

**Входные примитивы:** отрезки (`Line`).

**Диалог**

```
Введите значение нагрузки в начале в тоннах:
Введите значение нагрузки в конце в тоннах:
```

**Что создаётся**

| Параметр | Значение |
|---|---|
| Тип модели | `TM_LOAD_2` (131093) |
| Осевая линия | начало = `StartPoint × 0.001`, конец = `EndPoint × 0.001` |
| `M_LOAD_1` | нагрузка в начале |
| `M_LOAD_2` | нагрузка в конце |

Значения запрашиваются **один раз** на команду и применяются ко всем выбранным отрезкам. Диалог `AutoParametersDlg` не вызывается.

## Сравнение

| | `Sapfir_Point_LOADS` | `Sapfir_Line_LOADS` | `Sapfir_Line_LOADS2` |
|---|---|---|---|
| Примитив | точка | отрезок | отрезок |
| Форма эпюры | точечная | прямоугольная | трапециевидная |
| Запросов значений | 1 | 1 | 2 |
| Диалог САПФИР | нет | **на каждую линию** | нет |
| Материал | не запрашивается | не запрашивается | не запрашивается |

!!! note "О связывании"
    Нагрузки не получают XData-ID — редактировать их геометрию из AutoCAD повторно нельзя, только создавать заново (предварительно удалив старые в САПФИР).
