# Проёмы

Две команды создают проёмы **в существующих стенах** САПФИР: сначала плагин находит стены в активном этаже, затем проверяет, лежит ли линия проёма на оси стены (коллинеарность), и только после этого создаёт проём.

## Sapfir_DOORS

Создаёт дверные проёмы.

**Входные примитивы:** отрезки (`Line`) — линия двери вдоль оси стены.

**Диалог**

```
Введите высоту проема в метрах:
```

**Алгоритм**

1. `ResolveActiveContext()` — определение активного этажа.
2. Ввод высоты проёма.
3. Выбор отрезков.
4. Поиск стен активного этажа (`GetWalls`): перебираются все модели этажа, отбираются с `TypeModel == TM_WALL` (10).
5. Для каждого отрезка проверяется коллинеарность с осью каждой стены:

```csharp
Line2d wallLine = new Line2d(
    new Point2d(crd[0] * 1000, crd[1] * 1000),   // ось стены: м → мм
    new Point2d(crd[3] * 1000, crd[4] * 1000));
Line2d doorLine = new Line2d(
    new Point2d(line.StartPoint.X, line.StartPoint.Y),
    new Point2d(line.EndPoint.X, line.EndPoint.Y));
Tolerance tol = new Tolerance(1E-8, 1E-8);
if (wallLine.IsColinearTo(doorLine, tol)) { /* создаём проём */ }
```

6. Если линия коллинеарна оси стены → в этой стене создаётся проём.

**Что создаётся** (`wall.NewHole(...)`)

| Параметр | Значение |
|---|---|
| Тип модели | `TM_DOOR` (32) |
| `B` | длина отрезка двери, м |
| `H` | введённая высота, м |
| `M_POS` | расстояние от начала оси стены до ближайшего конца отрезка двери, м |

```
(сообщения о созданных проёмах не выводятся)
```

## Sapfir_WINDOWS

Создаёт оконные проёмы. Логика полностью совпадает с `Sapfir_DOORS`, отличаются тип модели и подсказка ввода.

**Диалог**

```
Введите высоту окна в метрах:
```

**Что создаётся**

| Параметр | Значение |
|---|---|
| Тип модели | `TM_WINDOW` (31) |
| `B` | длина отрезка окна, м |
| `H` | введённая высота, м |
| `M_POS` | смещение от начала стены, м |

!!! warning "Проёмы создаются только в стенах текущего этажа"
    Поиск стен (`GetWalls`) ограничен **активным этажом САПФИР**. Если стены были созданы на другом этаже (или вы переключили активный этаж в САПФИР), проём не создастся — команда просто не найдёт подходящих стен, и ничего не произойдёт.

!!! warning "Коллинеарность, а не пересечение"
    Линия проёма должна лежать **на оси стены** (в пределах допуска `1E-8`). Отрезок, нарисованный рядом или под углом, будет проигнорирован без сообщения об ошибке.

!!! tip "Один отрезок — один проём"
    Если отрезок коллинеарен сразу нескольким стенам (например, две стены на одной оси встык), проём будет создан в **каждой** из них.

!!! note "XData не записывается"
    Проёмы не получают связи с примитивами AutoCAD — обновить их геометрию из чертежа нельзя.
