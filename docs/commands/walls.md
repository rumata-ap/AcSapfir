# Стены

## Sapfir_WALLS

Создаёт стены по средним линиям, заданным отрезками AutoCAD.

**Входные примитивы:** отрезки (`Line`) — ось стены.

**Предварительные шаги**

1. Выбор материала («Стены»).
2. Ввод толщины:

```
Введите толщину стен в метрах:
```

**Что создаётся**

| Параметр | Значение |
|---|---|
| Тип модели | `TM_WALL` (10) |
| Осевая линия | `GetAxisLine()` + `SetPoints(начало, конец)` в метрах |
| `M_THICKNESS` | введённая толщина, м |
| `M_CONSTYPE` | `M_CTP_BEAR` (несущая) |
| `M_CR_FILL` | `11854048` |
| `M_CR_LINE` | `7369618` |
| `M_MATERIAL` | выбранный GUID, иначе `ab7d2fa2-df44-4d8f-8d46-71b7fb919bde` (Бетон тяжёлый, стена) |

Материал по умолчанию подставляется **жёстко**, если пользователь пропустил выбор (кнопка «Пропустить (по умолчанию)»).

ID стены записывается в отрезок через XData:

```
  Материал: Бетон тяжёлый (стена)
  Стена ID=12
  Стена ID=13
```

!!! warning "Направление оси и толщина"
    Толщина откладывается САПФИР самостоятельно (симметрично относительно осевой линии), сторонность в чертеже задать нельзя. Толщина вводится в **метрах**, координаты в чертеже — в миллиметрах.

## Sapfir_WALL_EDIT

Обновляет геометрию **уже созданных** стен по изменённым примитивам AutoCAD. Работает через XData-связь.

**Входные примитивы:** отрезки и/или полилинии, у которых в XData есть ID стены.

**Алгоритм**

1. Для каждого выбранного примитива читается XData-ID (`ACSAPFIR_ID`).
2. Если ID нет (`0`) — примитив пропускается.
3. В активном этаже по ID находится модель стены (`storeySpf.GetModelByID(spfId)`).
4. Геометрия осевой линии обновляется:
   - полилиния → все вершины (`SetPoints`), `Z = 0`;
   - отрезок → начало и конец.
5. Вызывается `RegenModel()`.

**Что НЕ обновляется:** толщина, материал, тип конструкции и цвет — только геометрия осевой линии.

```
(при успехе команда не выводит сообщений; ошибки проглатываются)
```

!!! note "Молчаливая обработка ошибок"
    Тело цикла обёрнуто в `try { ... } catch { }` — если объект не найден или произошла ошибка COM, она будет проигнорирована без сообщения. Если стена «не обновилась», проверьте командой `Sapfir_WALLS`-совместимость: примитив должен быть создан плагином (иметь XData), а стена — существовать в **активном** этаже.

!!! tip "Проверить наличие связи"
    Быстрый способ — вывести XData примитива в AutoCAD (команда `XDATA` в вашей версии AutoCAD или сторонний просмотрщик). Имя приложения — `ACSAPFIR_ID`.
