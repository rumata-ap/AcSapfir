# Балки

## Sapfir_BEAMS

Создаёт балки прямоугольного сечения по отрезкам — ось балки совпадает с отрезком.

**Входные примитивы:** отрезки (`Line`) — ось балки.

**Порядок работы**

1. `ResolveActiveContext()`.
2. Выбор материала («Балки»).
3. Ввод размеров сечения:

```
Введите высоту сечения балки в метрах:
Введите ширину сечения балки в метрах:
```

где **высота `h`** — размер по вертикали (Y контура), **ширина `b`** — по горизонтали (X контура). Оба значения — до применения угла поворота, поворот сечения не поддерживается.

4. Выбор отрезков и создание балок.

**Что создаётся**

| Параметр | Значение |
|---|---|
| Тип модели | `TM_BEAM` (13) |
| `M_POS_X`, `M_POS_Y` | середина отрезка: `(X₁+X₂)·0.0005`, `(Y₁+Y₂)·0.0005` (м) |
| Осевая линия | `GetAxisLine()` + `SetPoints(начало, конец)` в метрах |
| Контур сечения | прямоугольник с центром в начале координат: `(−b/2, −h/2) → (b/2, −h/2) → (b/2, h/2) → (−b/2, h/2) → (−b/2, −h/2)`, `Closed = 0` |
| `M_SIZE_GRO`, `M_SIZE_GRC` | `0` |
| `AddToLibPrj()` | сечение добавляется в библиотеку проекта |
| `M_MATERIAL` | выбранный GUID (если выбор не пропущен) |

После заполнения вызывается `RegenModel()`, ID балки записывается в отрезок:

```
  Балка ID=41, h=0,60м, b=0,30м
```

!!! note "Порядок ввода: сначала высота"
    Первым запрашивается `h` (высота), вторым `b` (ширина). В отчёте AutoCAD размеры выводятся в порядке `h`, `b`.

!!! note "Материал необязателен"
    При нажатии «Пропустить (по умолчанию)» параметр `M_MATERIAL` **не задаётся вовсе** (в отличие от стен и плит, где подставляется материал по умолчанию) — балка унаследует материал, назначенный в САПФИР по умолчанию.

!!! warning "Совместимость с САПФИР 2018+"
    Балки в САПФИР — балочный элемент (`TM_BEAM`); контур сечения добавляется в библиотеку проекта через `AddToLibPrj()`. Если библиотека проекта недоступна (нет проекта), создание может завершиться ошибкой COM.
