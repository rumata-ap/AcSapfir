# Колонны

## Sapfir_COLUMNS

Создаёт колонны: **сечение берётся из контура полилинии**, центр тяжести контура становится точкой позиционирования колонны.

**Входные примитивы:** `Polyline` — сечение колонны (замкнутое или незамкнутое, как минимум 2 вершины).

**Порядок работы**

1. `ResolveActiveContext()`.
2. Выбор материала («Колонны»).
3. Выбор полилиний-сечений.
4. Запрос угла поворота:

```
Задайте угол поворота сечения [Авто/по Двум точкам]:
```

| Вариант | Поведение |
|---|---|
| `Авто` (по умолчанию, `Enter`) | угол = 0° |
| `Две точки` | запрашиваются две точки, угол = `atan2(dy, dx)` по направлению «первая → вторая» |

5. Для каждой полилинии создаётся колонна.

**Геометрия**

1. Вычисляется центроид по всем вершинам: `cx = Σ X / n · 0.001`, `cy = Σ Y / n · 0.001` (м).
2. Вершины контура записываются **относительно центроида**.
3. Если полилиния замкнута (флаг `Closed` или совпадение первой и последней вершины с точностью `1e-9`), первая вершина дублируется в конце.

**Что создаётся**

| Параметр | Значение |
|---|---|
| Тип модели | `TM_COLUMN` (12) |
| `M_POS_X`, `M_POS_Y` | центроид контура, м |
| Контур сечения | `GetMultiContour().GetContour().NewPolyLine()`, `Closed = 0`, вершины относительно центра |
| `M_SIZE_GRO`, `M_SIZE_GRC` | `0` (подгонка размеров/положения не выполняется) |
| `AddToLibPrj()` | контур добавляется в библиотеку проекта |
| `M_HEIGHT` | высота этажа (см. примечание ниже) |
| `M_ANGLE` | угол в **градусах** |
| `M_MATERIAL` | выбранный GUID (если выбор не пропущен) |

```
  Колонна ID=31, угол=0,0°
```

!!! warning "Известная особенность: высота колонны"
    Высота берётся из параметра этажа `M_LEVEL`:

    ```csharp
    double storeyHeight = 3.0;
    try { storeyHeight = (double)storeySpf.Parameter["M_LEVEL"]; } catch { }
    ```

    Но `M_LEVEL` у этажа — это **отметка**, а не высота (высота хранится в `M_HEIGHT`, см. [`Sapfir_STOREYS`](storeys.md)). Поэтому при ненулевых отметках высота колонны получится неверной, а для этажей без `M_LEVEL` используется значение по умолчанию **3,0 м**. Проверяйте `M_HEIGHT` колонн после экспорта.

!!! note "Авто-угол"
    Режим «Авто» не анализирует геометрию контура — угол просто равен 0°. Для поворота сечения используйте режим «Две точки».

!!! note "XData"
    ID колонны записывается в полилинию — связь доступна для дальнейших операций.
