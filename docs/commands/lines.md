# Линии построения

## Sapfir_LINES

Создаёт в САПФИР линии построения (вспомогательная геометрия) по отрезкам AutoCAD.

**Входные примитивы:** отрезки (`Line`).

**Порядок работы**

1. `ResolveActiveContext()`.
2. Выбор отрезков (диалогов и запросов значений нет).
3. Для каждого отрезка создаётся линия построения.

**Что создаётся**

| Параметр | Значение |
|---|---|
| Тип модели | `TM_LINE` (18) |
| Осевая линия | `GetAxisLine()` + `AddLine(TM3_LINE (1), точки)` |
| Координаты | начало `(X₁·0.001, Y₁·0.001, 0)`, конец `(X₂·0.001, Y₂·0.001, 0)` |

После создания вызывается `RegenModel()`, ID записывается в отрезок через XData:

```
  Линия ID=52
```

**Когда использовать**

- как «репер» геометрии на плане (сетка, направляющие линии);
- как временная опорная геометрия для привязок в САПФИР;
- для проверки координат: линия построения создаётся напрямую из координат AutoCAD, поэтому визуально подтверждает корректность масштабирования (`×0.001`).

!!! note "Материал не запрашивается"
    Линии построения не являются конструктивными элементами, поэтому диалог выбора материала не показывается.
