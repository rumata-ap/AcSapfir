# Плиты

## Sapfir_SLABS

Создаёт плиты перекрытия из замкнутых полилиний.

**Входные примитивы:** `Polyline` (контур плиты). Вершины берутся по порядку обхода, каждая — в метрах (`×0.001`), `Z = 0`.

**Предварительные шаги**

1. Выбор материала (диалог «Выбор материала для: Плиты перекрытия»).
2. Ввод толщины:

```
Введите толщину плит в метрах:
```

**Что создаётся**

| Параметр | Значение |
|---|---|
| Тип модели | `TM_SLAB` (11) |
| Осевая линия | контур из вершин полилинии |
| `M_THICKNESS` | введённая толщина, м |
| `M_CONSTYPE` | `M_CTP_BEAR` (несущая конструкция) |
| `M_CR_FILL` | `12832210` |
| `M_CR_LINE` | `2318692` |
| `M_MATERIAL` | выбранный GUID, иначе `79f404bd-50e9-4058-b664-c159ffdd0ce8` |
| `M_TYPE_LEVEL` | `M_LEVEL_UP` (плита «наверх» этажа) |

ID созданной плиты записывается в полилинию через XData:

```
  Плита ID=14
```

## Sapfir_SLAB_Holes

Создаёт отверстия в существующей плите по контурам-полилиниям.

**Порядок работы — два отдельных выбора!**

1. Запрос **одной** полилинии плиты:

```
Выберите полилинию плиты:
```

2. Читается XData-ID плиты. Если ID нет — команда останавливается:

```
Выбранная полилиния не содержит ID плиты Sapfir.
```

3. Затем выбираются полилинии-контуры отверстий (PickFirst или запрос выбора).
4. Для каждого контура создаётся отверстие в найденной плите.

**Что создаётся** (найденная плита → `NewHole`)

| Параметр | Значение |
|---|---|
| Тип модели | `TM_HOLE` (30) |
| Осевая линия | контур отверстия по вершинам полилинии |
| Позиция | первая вершина контура (`SetPosition(X₀, Y₀, 0)`) |

После обработки всех отверстий плита перегенерируется (`RegenModel`).

!!! tip "Как найти плиту с ID"
    Плиту создаёт команда [`Sapfir_SLABS`](#sapfir_slabs) — она же и записывает ID в полилинию. Плита, созданная вручную в САПФИР, не имеет связи с чертежом, и отверстие к ней так создать нельзя.

## Sapfir_Found_SLABS

Создаёт фундаментные плиты из замкнутых полилиний.

**Входные примитивы:** `Polyline`.

**Предварительные шаги**

1. Выбор материала («Фундаментные плиты»).
2. Ввод толщины:

```
Введите толщину фундаментных плит в метрах:
```

**Что создаётся**

| Параметр | Значение |
|---|---|
| Тип модели | `TM_SLAB_1` (65547) |
| `M_THICKNESS` | введённая толщина, м |
| `M_CONSTYPE` | `M_CTP_BEAR` |
| `M_CR_FILL` | `9876679` |
| `M_CR_LINE` | `2785991` |
| `M_MATERIAL` | выбранный GUID, иначе `239d15bb-4253-4546-89f1-2d90300a3c79` |
| `M_TYPE_LEVEL` | `M_LEVEL_DN` (плита «вниз» этажа) |

```
  Фунд.плита ID=21
```

XData-ID записывается — связь доступна для дальнейших операций.

## Сравнение плит

| | `Sapfir_SLABS` | `Sapfir_Found_SLABS` |
|---|---|---|
| Тип модели | `TM_SLAB` (11) | `TM_SLAB_1` (65547) |
| Положение относительно этажа | `M_LEVEL_UP` | `M_LEVEL_DN` |
| Материал по умолчанию | Бетон тяжёлый (плита) | Бетон тяжёлый (фундамент) |
| XData-ID | да | да |
