# Мастер осей

`Sapfir_AXES_WIZ` — модальный мастер для автоматической маркировки координационных осей. Открывается после выбора отрезков.

## Окно мастера

- Заголовок: «Мастер координационных осей».
- Строка состояния: `Линий: N, групп: M`.
- Список групп: для каждой — заголовок `Группа K (n линий, вектор X,Y)`, выпадающий список правила, поля параметров, строка предпросмотра и флажок «В обратном порядке».
- Кнопки: **Создать оси** / **Отмена**.

## Как формируются группы

1. Берётся первый необработанный отрезок; вычисляется единичный вектор направления.
2. В группу добавляются все отрезки с `|cos(угла)| > 0.999` — то есть параллельные (или антипараллельные) линии.
3. Внутри группы линии сортируются по проекции середины на перпендикуляр к направлению группы: порядок соответствует реальному расположению осей (например, слева направо для вертикальных осей).
4. Отрезки нулевой длины игнорируются.

Настройки каждой группы независимы: можно задать разные правила, стартовые значения и направления нумерации.

## Правила именования

| № | Правило | Параметры | Результат |
|---|---|---|---|
| 0 | **Буквы кириллицей** | начальная буква | `А`, `Б`, `В`, … (алфавит: `АБВГДЕЖИКЛМНОПРСТУФХЦЧШЩЫЭЮЯ`, 28 букв) |
| 1 | **Цифры** | начало (`1…999`), шаг (`1…100`) | `1`, `2`, `3`… или `1`, `3`, `5`… |
| 2 | **Буквы + цифры** | начало (число) | `А1`, `Б1`, `В1`… (буква циклически повторяется) |
| 3 | **Шаблон** | номер (`{N}`), буква (`{L}`) | подстановка в шаблон, например `Ось {N}` → `Ось 1` |
| 4 | **Без маркировки** | — | пустые имена; в САПФИР марка не выводится, в отчёте AutoCAD — `(без маркировки)` |

Во всех правилах, кроме «Без маркировки», доступен флажок **«В обратном порядке»** — он переворачивает список имён внутри группы.

### Правило «Шаблон»

Поддерживаются два подстановочных элемента:

- `{L}` — буква кириллицы (последовательно от выбранной начальной);
- `{N}` — число (последовательно от выбранного начала).

Примеры: `Ось {L}` → `Ось А`, `Ось Б`; `{L}{N}` → `А1`, `Б2`, `В3`…; `К-{N}` → `К-1`, `К-2`.

!!! warning "Шаблон по умолчанию"
    В поле шаблона изначально подставлено значение `Ось {0}`, в котором **нет** ни `{L}`, ни `{N}` — подстановка не выполнится, и все оси получат одинаковое имя `Ось {0}`. Перед созданием замените шаблон на `Ось {L}` или `Ось {N}`.

### Ограничения правил

!!! note "Буквы и длина группы"
    В правиле «Буквы кириллицей» алфавит конечен (28 букв). Если линий в группе больше, чем осталось букв от выбранной начальной, «лишние» оси получат **пустое имя** — генерация останавливается на конце алфавита.

!!! note "Буквы + цифры"
    Буквенная часть циклится по алфавиту от `А` (начальная буква не выбирается), числовая часть одинакова для всех осей группы (задаётся полем «Начало»). Для последовательного «А1, Б2, В3» используйте правило «Шаблон» с `{L}{N}`.

## Предпросмотр

Строка под полями показывает итоговые имена: `→ А, Б, В, Г` (для правила «Без маркировки» — `→ без маркировки (n осей)`). Предпросмотр обновляется при изменении шаблона и флажка «В обратном порядке».

## Что происходит после нажатия «Создать оси»

1. Формируется список пар (отрезок, имя) по всем группам.
2. Если список пуст — сообщение «Нет осей для создания.» и окно остаётся открытым.
3. Для каждого отрезка создаётся осевой объект САПФИР:

| Параметр | Значение |
|---|---|
| Тип модели | `TM_DIMENSION` (20) |
| `SetDimParam` | `DIM_AXIS` (8), `DIM_DIR_XY` (3), имя, координаты начала и конца |
| `M_MARK` | имя оси |

4. В командную строку выводится по строке на каждую ось:

```
  Ось А
  Ось Б
  Ось (без маркировки)
```

## Отличия от Sapfir_AXES

| | `Sapfir_AXES` | `Sapfir_AXES_WIZ` |
|---|---|---|
| Маркировка | порядковый номер | буквы / цифры / шаблон / без марки |
| Группировка параллельных линий | нет (единый список) | да, автоматически |
| Порядок имён | порядок выбора в AutoCAD | геометрический порядок внутри группы |
| Окно настройки | нет | да |
