# Решение проблем

## Подключение к САПФИР

### «Ошибка подключения к САПФИР: …» + «Убедитесь, что САПФИР запущен…»

Конструктор команды не смог создать COM-объект или получить документ.

| Причина | Что делать |
|---|---|
| САПФИР не запущен | запустите САПФИР до вызова команды плагина |
| COM-класс не зарегистрирован (HRESULT `0x80040154`) | переустановите/отремонтируйте САПФИР |
| Разрядность/разные сессии | AutoCAD и САПФИР должны работать в одной пользовательской сессии |
| САПФИР запущен «от администратора», AutoCAD — нет (или наоборот) | запустите оба приложения от одного пользователя и с одинаковыми правами |

### Объекты уходят не в тот документ/этаж

Перед каждой командой вызывается `ResolveActiveContext()`, который читает **активное окно САПФИР**. Если переключиться на другой документ, следующая команда запишет объекты туда. Проверяйте строку контекста в командной строке AutoCAD:

```
[Sapfir] Активно: <документ> / проект ID=1 / этажей: 3
```

### Ничего не происходит, сообщений нет

Проверьте набор выбора: если вы нажали `Esc` при запросе выбора, команда молча завершается (`Selection()` вернул `null`). Повторите команду и выберите объекты.

## Проёмы не создаются

1. **Проёмы ставятся только в стены активного этажа.** Список стен берётся из моделей активного этажа с типом `TM_WALL`. Если активен другой этаж — стен «не найдётся».
2. **Линия проёма должна быть коллинеарна оси стены** с допуском `1E-8`. Небольшой сдвиг или поворот — и отрезок будет молча проигнорирован.
3. Стены должны быть созданы плагином в текущем сеансе проекта; стена, созданная вручную, тоже подойдёт (поиск идёт по типу модели, а не по XData).

## Колонны: неверная высота

В команде `Sapfir_COLUMNS` высота читается из параметра этажа `M_LEVEL` (это **отметка**, а не высота) и по умолчанию равна 3,0 м. Проверяйте и при необходимости исправляйте `M_HEIGHT` колонн в САПФИР. Подробнее — в [описании команды](../commands/columns.md#sapfir_columns).

## Материалы

| Симптом | Причина / решение |
|---|---|
| В диалоге всегда «Встроенные материалы (5)» | в открытых проектах нет моделей материалов (типы 251/252) — создайте материал в САПФИР |
| Долгое открытие диалога | сканируются все открытые документы САПФИР, все проекты, этажи и модели |
| Материал не применился к колоннам/балкам | эти команды не задают материал при нажатии «Пропустить (по умолчанию)» |

## Оси и маркировка

| Симптом | Причина |
|---|---|
| Все оси получили имя `Ось {0}` | в правиле «Шаблон» остался шаблон по умолчанию без подстановок `{L}`/`{N}` |
| Часть осей без имён | в правиле «Буквы кириллицей» не хватило букв алфавита (28 букв) |
| Порядок осей «неправильный» | порядок задаёт проекция середины линии на перпендикуляр к направлению группы; для точного контроля используйте правило или правьте имена вручную |

## Этажи

| Симптом | Причина |
|---|---|
| После `Sapfir_STOREYS` исчезли все прежние этажи | команда удаляет существующие этажи перед созданием новых — это штатное поведение |
| «Нет активного документа Sapfir» | команда `Sapfir_STOREYS` не создаёт документ сама — откройте документ в САПФИР |
| Отметки этажей неверные | Y-координата точки вставки `MText` трактуется как отметка в **миллиметрах** |
| Высоты этажей неверные | высота = разность с вышестоящим этажом; верхний этаж получает 3,0 м |

## Загрузка плагина в AutoCAD

| Симптом | Решение |
|---|---|
| «Не удаётся загрузить сборку» | проверьте .NET Framework 4.8 и разблокируйте DLL: `Unblock-File .\AcSapfir.dll` |
| Команда не найдена | убедитесь, что загружена свежая DLL; при повторной сборке перезапустите AutoCAD |
| Сборка падает на `accoremgd`/`acdbmgd`/`acmgd` | поправьте `HintPath` в `AcSapfir.csproj` под ваш путь AutoCAD |
| Сборка падает на `SapfirLib` | нужен установленный САПФИР; используйте MSBuild из Visual Studio, а не `dotnet build` |

## Дубликаты объектов

Повторный запуск команд экспорта создаёт **новые** объекты САПФИР, не заменяя прежние (исключение — `Sapfir_WALL_EDIT`, который обновляет геометрию). Перед повторным экспортом удалите прежние объекты в САПФИР либо пользуйтесь `Sapfir_WALL_EDIT` для геометрии.

## Масштаб координат

Объекты оказываются в 1000 раз больше/меньше ожидаемого — признак того, что чертёж нарисован не в миллиметрах. Плагин жёстко использует коэффициент `0.001` (мм → м). Приведите чертёж к миллиметрам (`SCALE` с коэффициентом) либо учтите это при чтении результатов.

## Что приложить к обращению о проблеме

1. Версия AutoCAD и САПФИР.
2. Текст из командной строки AutoCAD (окно `F2`) — включая строку `[Sapfir] Активно: …`.
3. Какой командой пользовались и какие примитивы выбирали (отрезки/полилинии/точки/`MText`).
4. Сработал ли диалог выбора материала и что было нажато.
