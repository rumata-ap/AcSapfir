# Генератор этажей

`Sapfir_STOREYS_WIZ` открывает модальное окно **«Генератор этажей»** — табличный способ создать этажи без текстов в чертеже.

## Состав окна

| Элемент | Назначение |
|---|---|
| Таблица «Имя этажа / Отметка, м» | список этажей; отметка — абсолютная, в метрах |
| **Добавить** | новая строка; имя по умолчанию — `N этаж` (N = текущее число строк + 1), отметка `0.00` |
| **Удалить** | удалить выбранную строку |
| **▲ / ▼** | переместить строку вверх/вниз |
| **Подвал** | добавить строку «Подвал» с отметкой `−3.0` м |
| **1-й этаж** | добавить строку «1 этаж» с отметкой `0.0` м |
| **Типовые × N** | добавить N типовых этажей подряд (см. ниже) |
| **Чердак** | добавить «Чердак» с отметкой = максимальная отметка в таблице + высота этажа |
| Строка состояния | контекст САПФИР: `Sapfir: <документ> / Проект ID=<n> / этажей: <m>` |
| **Создать этажи** / **Отмена** | применить или отменить |

## Шаблон «Типовые × N»

Параметры: **количество** (1…99, по умолчанию 3) и **высота этажа** (0,5…20 м с шагом 0,1; по умолчанию 3,0).

Как это работает:

1. Базовая отметка — **максимальная** отметка в таблице (`GetTopElevation`), а не отметка последней строки.
2. Этажи добавляются по одному: отметка каждого следующего = базовая + `i × высота`.
3. Имена: первый — «1 этаж», второй — «2 этаж», третий — «3 этаж», далее «N этаж».
4. Счётчик номеров **не сбрасывается** между нажатиями кнопки: если нажать «Типовые × 3» дважды, вторая серия начнётся с номера 4.

!!! warning "Имена типовых этажей — не «Тип», а номера"
    Генератор присваивает этажам числовые имена («4 этаж», «5 этаж», …). Переименование — вручную в таблице (двойной клик по ячейке) до нажатия «Создать этажи».

!!! note "Отметки вводятся с точкой"
    Разбор отметок выполняется в инвариантной культуре (`InvariantCulture`): десятичный разделитель — **точка** (`3.00`). Значение `3,00` с запятой не будет распознано, и строка при создании будет пропущена.

## Что учитывается при создании

- Строки с пустым именем или неразбираемой отметкой **отбрасываются**.
- Если пригодных строк нет — сообщение «Добавьте хотя бы один этаж.» и окно остаётся открытым.
- Данные сортируются **по возрастанию отметки**.
- Существующие этажи активного проекта удаляются, затем создаются новые:

| Параметр | Значение |
|---|---|
| `M_LEVEL` | отметка из таблицы, м |
| `M_HEIGHT` | разность отметок с вышестоящим этажом; для верхнего этажа — `3.0` м |

## Отличия от `Sapfir_STOREYS`

| | `Sapfir_STOREYS` | `Sapfir_STOREYS_WIZ` |
|---|---|---|
| Источник данных | `MText` в чертеже | таблица в окне |
| Требуется открытый документ САПФИР до запуска | да | нет (контекст создаётся автоматически) |
| Шаблоны решений | нет | Подвал / 1-й этаж / Типовые / Чердак |
| Ручная правка отметок | редактированием текста в чертеже | прямо в таблице |

!!! tip "Разумный порядок работы"
    Сначала создайте этажи (любой из двух команд), затем в САПФИР выберите нужный этаж как активный и только после этого экспортируйте стены/плиты/колонны — элементы попадут на активный этаж.
