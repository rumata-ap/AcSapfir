# Документация AcSapfir

Папка для проектной документации: описания команд, спецификации, архитектурные заметки.

## Что здесь есть

| Раздел | Назначение |
|---|---|
| `README.md` | этот файл — точка входа в документацию |
| другие файлы и подпапки | добавляются по мере необходимости и отслеживаются репозиторием |

## Что здесь намеренно отсутствует

Локальные рабочие заметки планирования (`docs/superpowers/**`) в репозиторий не попадают — эта подпапка исключена в `.gitignore` и существует только на локальной машине разработчика.

## Как добавить документ

Любой файл, положенный прямо в `docs/` или в новую подпапку, отслеживается обычным образом:

```bash
git add docs/spec.md
git commit -m "Add docs: spec"
git push
```
