# Масштабирование координат

AutoCAD-чертежи проекта ведутся в **миллиметрах**, расчётные схемы САПФИР — в **метрах**. Плагин переводит координаты коэффициентом `0.001` — жёстко, без настройки.

## Правила перевода

| Что | Откуда | Куда | Коэффициент |
|---|---|---|---|
| Плоские координаты XY | `Line.StartPoint.X`, `Polyline.GetPoint2dAt(i)` и др. (мм) | `SetPoints`, `SetPosition`, `M_POS_X/Y` (м) | `× 0.001` |
| Отметка этажа | Y точки вставки `MText` (мм) | `AutoStorey.Parameter["M_LEVEL"]` (м) | `× 0.001` |
| Высота этажа | разность отметок соседних `MText` (мм) | `M_HEIGHT` (м) | `× 0.001` |
| Z-координата геометрии | — | всегда `0` | — |
| Толщина стены/плиты, высота/ширина сечения | ввод пользователя | `M_THICKNESS`, `H`, `B` (м) | **не масштабируется** |
| Значения нагрузок | ввод пользователя | `M_LOAD_1`, `M_LOAD_2` (т) | **не масштабируется** |
| Угол поворота колонны | `atan2` (радианы) | `M_ANGLE` (градусы) | `× 180 / π` |

## Пример: ось стены

```csharp
buf1 = new object[]
{
    line.StartPoint.X * 0.001, line.StartPoint.Y * 0.001, 0,
    line.EndPoint.X   * 0.001, line.EndPoint.Y   * 0.001, 0
};
polylineSpf.SetPoints(buf1);
```

Отрезок `(0,0) → (12000,0)` в AutoCAD превращается в осевую линию `(0,0) → (12,0)` в САПФИР.

## Обратный перевод (м → мм)

Там, где нужно сравнить **прочитанную из САПФИР** геометрию с координатами AutoCAD, применяется обратный коэффициент `× 1000`. Так работают проверки коллинеарности в командах проёмов:

```csharp
Line2d wallLine = new Line2d(
    new Point2d(crd[0] * 1000, crd[1] * 1000),   // прочитано из САПФИР (м) → мм
    new Point2d(crd[3] * 1000, crd[4] * 1000));
Line2d doorLine = new Line2d(
    new Point2d(line.StartPoint.X, line.StartPoint.Y),   // уже в мм
    new Point2d(line.EndPoint.X, line.EndPoint.Y));
```

## Z всегда ноль

Все объекты создаются в плоскости `Z = 0` активного этажа:

| Объект | Как задаётся высота |
|---|---|
| Стены, плиты, колонны, балки, линии | вертикальное положение определяется **активным этажом** САПФИР, а не координатой Z чертежа |
| Отверстия в плите | `SetPosition(X₀, Y₀, 0)` |
| Этажи | отметка задаётся параметром `M_LEVEL` |

Поэтому «высотное» положение элемента из AutoCAD задать нельзя — переключите активный этаж в САПФИР перед экспортом.

## Отметки этажей в двух командах

Разница между командами создания этажей:

| Команда | Источник отметки | Единицы на входе | Что записывается |
|---|---|---|---|
| `Sapfir_STOREYS` | Y точки вставки `MText` | миллиметры | `M_LEVEL = Y · 0.001` |
| `Sapfir_STOREYS_WIZ` | столбец «Отметка, м» | метры | `M_LEVEL = значение` |

Высота этажа в обеих командах одинакова: разность отметок с вышестоящим этажом, для верхнего этажа — `3.0` м.

## Частые ошибки масштабирования

| Симптом | Причина |
|---|---|
| Объекты в 1000 раз больше/меньше | чертёж нарисован в метрах или сантиметрах вместо миллиметров |
| Этажи «накладываются» друг на друга | отметки `MText` введены в метрах, а команда ожидает миллиметры |
| Стены тонкие/толстые | толщина вводится в метрах — `0.2`, а не `200` |
| Нагрузки в 1000 раз больше | величина нагрузки — в тоннах, не в Ньютонах/кгс |

!!! tip "Проверка масштаба"
    Создайте командой `Sapfir_LINES` линию по известному отрезку и убедитесь, что её длина в САПФИР совпадает с ожидаемой в метрах. Это самый быстрый способ проверить согласованность единиц.
