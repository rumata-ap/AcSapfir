## 1.0.0 — 2026-09-21

Первый публичный релиз.

**Сборка:** `AcSapfir.dll`, .NET Framework 4.8, AnyCPU, `AssemblyVersion 1.0.0.0`.
Размер API AutoCAD в поставку не входит — DLL использует библиотеки установленного AutoCAD 2020.

### Добавлено

- **Оси:** `Sapfir_AXES` (из отрезков, нумерация по порядку) и `Sapfir_AXES_WIZ` — мастер с авто-группировкой параллельных линий и пятью правилами маркировки (буквы кириллицей, цифры, буквы + цифры, шаблон `{L}`/`{N}`, без маркировки), с предпросмотром и реверсом.
- **Стены:** `Sapfir_WALLS` (толщина, материал), `Sapfir_WALL_EDIT` — обновление геометрии существующих стен по XData-связи.
- **Плиты:** `Sapfir_SLABS` (перекрытия, `M_LEVEL_UP`), `Sapfir_Found_SLABS` (фундаментные, `M_LEVEL_DN`), `Sapfir_SLAB_Holes` — отверстия по контуру полилинии в конкретной плите.
- **Колонны:** `Sapfir_COLUMNS` — сечение из контура полилинии, центрирование по центроиду, угол «Авто» или по двум точкам.
- **Балки:** `Sapfir_BEAMS` — прямоугольное сечение h×b, контур добавляется в библиотеку проекта.
- **Проёмы:** `Sapfir_DOORS`, `Sapfir_WINDOWS` — с проверкой коллинеарности оси стены и расчётом смещения `M_POS`.
- **Нагрузки:** `Sapfir_Point_LOADS` (точечные), `Sapfir_Line_LOADS` (равномерные), `Sapfir_Line_LOADS2` (трапециевидные).
- **Этажи:** `Sapfir_STOREYS` (из `MText`: имя + Y-отметка), `Sapfir_STOREYS_WIZ` — генератор с шаблонами «Подвал / 1-й этаж / Типовые ×N / Чердак» и расчётом `M_HEIGHT` из разности отметок.
- **Линии построения:** `Sapfir_LINES`.
- **Материалы:** выбор из материалов открытого проекта САПФИР; встроенный набор из 5 материалов, если в проекте их нет.
- **XData-связь** `ACSAPFIR_ID`: ID объекта САПФИР сохраняется в примитиве AutoCAD.
- **Документация:** сайт <https://rumata-ap.github.io/AcSapfir/> (справочник команд, внутреннее устройство, решение проблем) и автоматическая публикация через GitHub Actions.
- **Лицензия:** MIT.

### Известные ограничения

Описаны подробно в разделе [Решение проблем](guides/troubleshooting.md):

- высота колонн читается из параметра этажа `M_LEVEL` (отметка, не высота) — типично получается 3,0 м;
- в мастере осей шаблон по умолчанию `Ось {0}` не содержит подстановок `{L}`/`{N}` — замените на `Ось {L}` или `Ось {N}`;
- `Sapfir_Line_LOADS` открывает диалог параметров САПФИР на каждую выбранную линию;
- проёмы создаются только в стенах **активного этажа** и только при строгой коллинеарности (допуск `1E-8`);
- `Sapfir_STOREYS` и `Sapfir_STOREYS_WIZ` удаляют все существующие этажи проекта перед созданием новых;
- геометрия читается в плоскости XY: высотное положение задаётся активным этажом, а не Z-координатой чертежа;
- плагин не выполняет расчёт — только готовит расчётную схему.
